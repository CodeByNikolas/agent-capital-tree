# AI assistance and submission provenance

The two-person team chose the product scope, partner integrations, policy model, user flows and acceptance criteria, and reviewed the resulting work. The tracked implementation began during ETHGlobal Tokyo 2026. Codex AI agents assisted with implementation, research, documentation, tests and UI iteration. Their contributions include the Solidity controller/vault/ENS code under `contracts/src/`, the TypeScript SDK, runtime, MCP/plugin and MultiBaas packages under `packages/`, the Next.js dashboard under `apps/web/`, and the integration scripts and written evidence. The UI also followed direct human feedback about readability, navigation, names and payments.

The tracked architecture and work-package specification is [PLAN.md](../PLAN.md). [STATUS.md](../STATUS.md) and [ACCEPTANCE.md](../ACCEPTANCE.md) distinguish tested behavior from open acceptance work; Git history contains incremental feature commits.
